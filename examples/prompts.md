# Requests

Ask in plain words. The agent finds the skill's claims, sizes the key, builds the target and writes the request; you read the key before the runs and the report after.

## A review skill

```text
Use blind-test to check whether my design-review skill finds more real problems than the agent does without it. Two runs per arm on Haiku.
```

## A build skill

```text
My skill builds dashboards from a brief. Build a blind test: a short brief, data at the usual size and at ten times the size, and checks written before the runs.
```

## Before publishing

```text
I'm about to publish this skill. Build a blind test for its three main claims and run it on Haiku with and without the skill. I need numbers for the listing, with their limits.
```

## Against another skill

```text
Compare my skill with this free one on the same target: a third arm in its own sandbox, the same request, the same model.
```

## A prompt or a rule file

```text
We added a rule file for code reviews. Test whether reviews with it catch more of the problems we care about, and whether it makes the agent flag things that are fine.
```

## A quick check

```text
I have an hour. Run a quick blind test of this skill: one target, a small key, two runs per arm, and tell me what a test that size can show.
```

## A test for someone else to run

```text
Prepare the test without running it: the target, the request and the run instructions in one folder for a colleague, and the key in a separate folder that goes only to the grader.
```

## After a fix

```text
I changed the skill after the last blind test. Rerun the same test with the same key and request, then once more on a new target the skill hasn't seen.
```
