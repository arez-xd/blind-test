# Logo source

`logo.html` draws the logo on a 1024 px WebGL canvas: the backdrop (`bg-only.svg`) and the eye with a keyhole pupil (`key-p1.svg`). The parameters of the published logo are in `final-params.txt`; open the page in a browser with WebGL 2:

```text
logo.html?k=p1&tint=.55&blur=40&bevel=14&hl=.5&gx=0&gy=0&gw=0&gh=0&rad=0
```

The banners are `../banner.html` and `../banner-square.html`, rendered at 2×.
